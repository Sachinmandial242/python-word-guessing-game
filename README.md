# 🎮 Word Guessing Game Using Python

## 📌 About the Project
Word Guessing Game is a simple console-based mini project developed using Python. In this game, the player has to guess a hidden word by entering one letter at a time.

The game selects a random word from a predefined list and provides three difficulty levels: Easy, Medium, and Hard.

## ✨ Features
- Three difficulty levels: Easy, Medium, and Hard.
- Random word selection.
- Guess the word one letter at a time.
- Display guessed letters.
- Input validation.
- Prevent repeated letter guesses.
- Track remaining attempts.
- Display winning and losing messages.

## 🛠️ Technologies Used
- Python 3
- Random Module
- Visual Studio Code

## 💻 How to Run the Project
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python word_guessing_game.py
```

6. Select a difficulty level.
7. Start guessing the hidden word.

## 🎯 Difficulty Levels

| Level | Attempts | Word Length |
|---|---:|---|
| Easy | 10 | 6 letters or fewer |
| Medium | 7 | 7–8 letters |
| Hard | 5 | More than 8 letters |

## 🖥️ Sample Output

The game displays the hidden word using underscores. Correct guesses reveal letters, while incorrect guesses reduce the remaining attempts.

At the end, the game displays a winning message or reveals the correct word if the player runs out of attempts.
